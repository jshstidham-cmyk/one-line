Auto-number is locked

This project's step order is protected. Auto-number would renumber every switching device top to bottom and throw away the current order, including any order set from the schedule. Procedure steps stay put, but devices would not.

To change one step, use ▲▼ in the sequence list or type a step number on the device. That still works while Auto-number is locked.
