# Energization One-Line

Installable web app for drawing a one-line, numbering the energization order,
walking the sequence step by step, and exporting the switching packet.

- App: open `index.html` from this site's GitHub Pages address, then use
  Add to Home Screen (iPhone/iPad, Safari) or Install app (Android, Chrome).
- Works offline after the first visit. Projects are saved on the device only.
- Setup and update steps: see `HOW-TO-INSTALL.txt`.
